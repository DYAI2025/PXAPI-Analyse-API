## D. What this slice delivers

### The problem it solves

PXK-67 makes the first real HTTP/HTML observation of a customer website. Before it runs, the
contract set must distinguish *"we measured, and the answer is 200"* from *"the provider timed
out"*. It could not. Left unsolved, that distinction lands in collector code, where a `TIMEOUT`
becomes a zero and a zero becomes a negative finding about a paying customer's website.

### Contract shapes

`contracts/v1/schemas/assessment.v1.json` — a **shared definition, not a registered contract**.
Every registered contract pins its own `schema_version` at its root
(`test_schema_meta.py::test_every_contract_is_a_closed_object_pinning_its_own_version`), so a
block embedded in two carriers would drag a nested version into every document that carries it.
Its internal `$ref`s are absolute URIs, because the block is resolved from whichever schema
embeds it and a local `#/$defs/…` would resolve nowhere. This was found by a failing test, not
by review — see section E.

```text
$defs/collection_mode      MEASURED | OBSERVED
$defs/result_state         KNOWN | UNKNOWN | CONFLICT | NOT_APPLICABLE
$defs/not_assessed_reason  PROVIDER_FAILURE | RUNTIME_ERROR | PERMISSION_DENIED
                           | TIMEOUT | UNSUPPORTED | NOT_REQUESTED
$defs/assessment           closed object; exactly one of the two groups, never both
```

`contracts/v1/schemas/measurement-record.v1.json` — registered, `1.0.0`:

```text
schema_version    Required     const 1.0.0
run_id            Required     common id
measurement_id    Required     common id          website evidence references this
metric_id         Required     common code        OPEN token, never an enum
source_url        Required     common url         observation context
observed_at       Required     common timestamp
collector         Required     common code        OPEN token
collector_version Required     common label
assessment        Required     shared assessment block
result            Conditional  present iff result_state is KNOWN
raw_artifact_ref  Optional     common id — an opaque token and nothing else
```

`result` is a closed discriminated shape, deliberately not an open node:

```text
value_type     Required     BOOLEAN | INTEGER | TEXT | URL
boolean_value  Conditional  iff value_type is BOOLEAN
integer_value  Conditional  iff value_type is INTEGER
text_value     Conditional  iff value_type is TEXT   (shared single-line bound)
url_value      Conditional  iff value_type is URL
```

`contracts/v1/schemas/website-evidence.v1.json` — registered, `1.0.0`:

```text
schema_version    Required
run_id            Required     common id
evidence_id       Required     common id
source_url        Required     common url
observed_at       Required     common timestamp
scenario          Required     common code        OPEN token
collector         Required     common code        OPEN token
collector_version Required     common label
assessment        Required     shared assessment block
polarity          Conditional  POSITIVE | NEGATIVE — permitted ONLY when KNOWN
measurement_refs  Required     unique common ids; at least one when KNOWN
```

### Legal and illegal combinations

| assessment | measurement `result` | evidence `polarity` | `measurement_refs` |
| --- | --- | --- | --- |
| `MEASURED` + `KNOWN` | **required** | permitted | ≥ 1 |
| `OBSERVED` + `KNOWN` | **required** | permitted | ≥ 1 |
| `MEASURED`/`OBSERVED` + `UNKNOWN` | refused | **refused** | may be empty |
| `MEASURED`/`OBSERVED` + `CONFLICT` | refused | **refused** | may be empty |
| `MEASURED`/`OBSERVED` + `NOT_APPLICABLE` | refused | **refused** | may be empty |
| `not_assessed_reason`, any of the six | refused | **refused** | may be empty |

Illegal by structure, with the violation each produces:

| Illegal document | Violation |
| --- | --- |
| `collection_mode` **and** `not_assessed_reason` together | `/assessment` `not` |
| performed, but no `result_state` | `/assessment` `required` |
| `result_state`, but no `collection_mode` | `/assessment` `required` |
| empty assessment | `/assessment` `required` |
| not assessed, but carrying a value | `""` `not` |
| `KNOWN`, but carrying no `result` | `""` `required` |
| any non-`KNOWN` carrying a polarity | `""` `not` |
| `KNOWN` evidence with zero `measurement_refs` | `/measurement_refs` `minItems` |
| a polarity of `NEUTRAL` | `/polarity` `enum` |
| a token outside any closed vocabulary | that member's `enum` |
| `value_type` disagreeing with the carried member | `/result` `required` |
| an inline raw HTML or response body | `""` `additionalProperties` |

**Polarity is permitted, not required**, and there is deliberately no `NEUTRAL` token. Evidence
that is `KNOWN` and carries no judgement omits the member, so nothing forces a factual
observation (a content type, a final URL) to be labelled good or bad. Outside `KNOWN` the member
is **refused outright** rather than given a neutral value to hold — which is the structural form
of "a provider failure cannot appear as a negative finding".

## F. Scope

### Nothing under `src/` changed

Every invariant in this slice is expressible in JSON Schema, so no stdlib semantic validator was
needed. `src/pxapi/**`, `pyproject.toml` and `uv.lock` are byte-identical to `main`.

### Explicit confirmation of what was NOT built

No HTTP collector. No FastAPI endpoint or any transport binding. No PXK-67 application
orchestrator. No persistence, PostgreSQL or SQLAlchemy. No browser, cookie or consent handling.
No `PrivacyEvidence`, `ConsentEvent`, `SecurityFinding`, `ThirdPartyCall` or `LegalSignal`. No
full `ArtifactDescriptor`. No `ScoreModelDefinition`, `Scorecard`, `ProductDiagnosis` or customer
report. No Google, AI or competitor integration. No deployment, authentication or authorisation.

PR #5 remains a frozen, unmerged reuse source at `ed9814b96a96cb57ad4460709c50fed599727794`. It
was read and not modified, and nothing was branched from it. Its `measurement-record` and
`website-evidence` shapes were **not** ported: they carry an open `value: any` node, a required
polarity with a `NEUTRAL` token, a `confidence` scale, a `collection_pass` vocabulary and an
`artifact_ref` descriptor, none of which the current authority supports.

### Is this enough for PXK-67?

Yes, and that is a test result rather than an assertion.
`test_every_observation_the_next_slice_needs_is_representable` expresses each observation PXK-67
will make through the contracts as they now stand — HTTP status, final URL, content type,
whether the transport was HTTPS, title present and title value, meta description present and
value, canonical present and canonical URL — and each validates with zero violations.
`test_every_way_the_next_slice_can_fail_is_representable_without_touching_the_website` does the
same for all six failure reasons, and additionally proves each one cannot carry a value.

The reservation is bounded and named: `text_value` inherits the shared single-line bound, so an
observed text longer than it is not representable in `1.0.0`. See section G.

## G. Blockers and follow-ups discovered

No blocker was found. Three items are named for later slices rather than pulled into this one:

1. **`text_value` is bounded by the shared single-line primitive.** A meta description longer
   than that bound is not representable in `measurement-record 1.0.0`. Widening it is a new
   contract version, never a widened bound on the existing one, because `$ref` plus a sibling
   `maxLength` intersect rather than widen.
2. **The full artifact descriptor** — digest, location, media type, size, retention, redaction —
   is deliberately absent. `raw_artifact_ref` is an opaque token, and a test asserts it has no
   structure of its own.
3. **Whether `CONFLICT` must reference the measurements it conflicts over** is left open. Only
   `KNOWN` requires at least one reference in this slice.

## H. Deliberately deferred

The `not_assessed_reason` vocabulary carries no severity and no retry policy. Whether a given
reason is worth retrying, and whether a failed measurement is fatal to a run, are orchestration
decisions that no contract here makes — the same boundary PXK-60 drew between a stage's own
status and the global run state.
